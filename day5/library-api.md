# Library Books REST API

## Overview

This REST API manages books in a library system. The main resource is `books`.

Base URL:

```text
https://api.example.com

API Endpoints
1. List All Books
- Method: GET
- Path: /books
- Description: Returns a list of all books in the library.
- Success Status: 200 OK
Example request:
GET /books

Example response:
[
  {
    "id": 1,
    "title": "Clean Code",
    "author": "Robert C. Martin",
    "isbn": "9780132350884",
    "publishedYear": 2008
  }
]

Get One Book
- Method: GET
- Path: /books/:id
- Description: Returns a single book using its unique ID.
- Success Status: 200 OK
Example request:
GET /books/42

Example response:
{
  "id": 42,
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "isbn": "9780132350884",
  "publishedYear": 2008
}

Create a Book
- Method: POST
- Path: /books
- Description: Creates a new book in the library.
- Success Status: 201 Created
 
 Example Request
POST /books
Content-Type: application/json

Example JSON Request Body
{
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "isbn": "9780132350884",
  "publishedYear": 2008
}

Update a Book
- Method: PUT
- Path: /books/:id
- Description: Updates an existing book using its ID.
- Success Status: 200 OK

Example Request
PUT /books/42
Content-Type: application/json

Example Response
{
  "id": 42,
  "title": "Clean Code - Updated Edition",
  "author": "Robert C. Martin",
  "isbn": "9780132350884",
  "publishedYear": 2008
}

Delete a Book
- Method: DELETE
- Path: /books/:id
- Description: Deletes a book using its unique ID.
- Success Status: 204 No Content

Example request:
DELETE /books/42

A successful delete request returns:
204 No Content

List Books by Author
- Method: GET
- Path: /books?author=Robert%20C.%20Martin
- Description: Returns books that match the supplied author query parameter.
- Success Status: 200 OK

Example request:
GET /books?author=Robert%20C.%20Martin

Example response:
[
  {
    "id": 42,
    "title": "Clean Code",
    "author": "Robert C. Martin",
    "isbn": "9780132350884",
    "publishedYear": 2008
  }
]

Error Responses
400 Bad Request
A 400 Bad Request response is returned when the client sends invalid or incomplete data.
For example, a client tries to create a book without providing the required title.

Example request body:
{
  "author": "Robert C. Martin",
  "isbn": "9780132350884",
  "publishedYear": 2008
}

Example response:
400 Bad Request

Example error response:
{
  "error": "Book title is required."
}


404 Not Found
A 404 Not Found response is returned when the requested book does not exist.

Example request:
GET /books/99999

If book 99999 does not exist, the API returns:
404 Not Found

Example response:
{
  "error": "Book not found."
}

Endpoint Summary
| Operation | Method | Path | Success Status |
|---|---|---|---|
| List all books | GET | `/books` | 200 OK |
| Get one book | GET | `/books/:id` | 200 OK |
| Create a book | POST | `/books` | 201 Created |
| Update a book | PUT | `/books/:id` | 200 OK |
| Delete a book | DELETE | `/books/:id` | 204 No Content |
| List books by author | GET | `/books?author=...` | 200 OK |

Book Data Schema
The standard book object returned by the API has the following structure:
{
  "id": 42,
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "isbn": "9780132350884",
  "publishedYear": 2008
}

| Field | Type | Description |
|---|---|---|
| `id` | integer | Unique identifier generated by the server |
| `title` | string | Title of the book |
| `author` | string | Author of the book |
| `isbn` | string | International Standard Book Number |
| `publishedYear` | integer | Year the book was published |
